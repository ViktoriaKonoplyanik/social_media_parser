# Парсер социальных сетей  

Асинхронный веб-сервис для автоматического поиска ссылок на социальные сети (VK, Telegram) с сайтов дилеров и сбора статистики по количеству подписчиков. 

## Стек технологий
* **Язык:** Python 3.11
* **Фреймворк:** FastAPI (веб-интерфейс и API)
* **Парсинг и сеть:** aiohttp, BeautifulSoup4
* **Инфраструктура:** Docker, Docker Compose

## Требования
Для локального запуска потребуется установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/).

## Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone <вставьте-сюда-ссылку-на-ваш-репозиторий>
   cd <название-папки-репозитория>
   
2. Настройка переменных (API Ключи)
Создайте конфигурационный файл .env в корневой папке проекта. Добавьте в него сервисный ключ доступа к API ВКонтакте (одной строкой без пробелов и кавычек):
    ```bash
    VK_TOKEN=ваш_сервисный_ключ_vk
   
3. Сборка и запуск
В терминале выполните команду для сборки и поднятия контейнера:
    ```bash
    docker-compose up --build
   
После успешного запуска веб-сервис будет доступен в браузере по адресу:
http://localhost:8085

## Инструкция по использованию

**Шаг 1. Вход в веб-интерфейс**
Откройте браузер и перейдите по локальному адресу .

**Шаг 2. Загрузка данных**
Загрузите исходный Excel-файл (`.xlsx`), содержащий данные дилеров (название ОП, город, сайты). 

**Шаг 3. Запуск анализа**
Нажмите кнопку старта. Парсинг выполняется асинхронно батчами по 10 записей. При возникновении сетевых таймаутов или блокировок у отдельных сайтов процесс не прерывается — ошибки перехватываются и логируются в финальную таблицу.

**Шаг 4. Выгрузка результата**
После завершения скачайте сгенерированный отчет. К исходным данным автоматически добавятся новые колонки:
* `Ссылка на аккаунт` — проверенный URL группы или канала.
* `Соц сеть` — тег VK или Telegram.
* `Кол-во подписчиков` — актуальная статистика на момент запуска.
* `Лог (Отладка)` — технический статус поиска для удобного траблшутинга.
